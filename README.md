# Family Time App Prototype

## Overview

Family Time is a mobile application prototype designed to encourage families to spend meaningful time together through shared digital activities, family challenges, progress tracking, and activity planning.

The project was developed as part of the Human Computer Interaction course. The main goal is to improve family bonding by transforming individual screen time into shared and engaging family experiences instead of simply restricting device usage.

## Problem Statement

In many families, technology use has reduced direct family interaction. Family members may sit in the same room while each person uses a personal device separately. This can reduce communication, shared enjoyment, and emotional connection.

Family Time addresses this issue by offering a positive and interactive solution that helps families plan activities, join challenges, track progress, and participate in shared games together.

## Project Goals

- Encourage meaningful family interaction
- Promote healthier digital habits
- Support shared activities instead of isolated screen use
- Provide an easy and engaging interface for parents and teenagers
- Improve usability through testing and user feedback

## Target Users

The prototype focuses on two main user groups:

- Parents who want to reduce excessive screen time and create more meaningful family moments
- Teenagers who enjoy games and challenges but need motivation to balance screen time with family activities

## Main Features

- User registration and login
- Family group joining using a family code or invitation
- Family activity planning
- Shared challenges
- Interactive family games
- Weekly progress dashboard
- Leaderboard and points system
- Notifications and reminders
- Settings customization
- Accessibility-friendly interface elements

## Usability Evaluation

A usability test was conducted with 15 participants representing the target users, including parents and teenagers. The evaluation measured:

- Effectiveness
- Efficiency
- Satisfaction

Participants completed realistic tasks such as creating a family activity, joining a challenge, checking the dashboard, and adjusting notification settings.

## Key Findings

The usability evaluation identified several issues:

- Some users were confused by the game timer interaction
- Some users had difficulty identifying game categories
- Some users had difficulty locating notification settings

Based on these findings, recommendations were proposed to improve labels, visual hierarchy, navigation clarity, and action buttons.
